# API Documentation

Interactive, always-current API docs are auto-generated by FastAPI and
served at:

- **Swagger UI:** `GET /api/docs`
- **ReDoc:** `GET /api/redoc`
- **Raw OpenAPI schema:** `GET /api/openapi.json`

This document is a human-readable summary of the same API for quick
reference. All endpoints below are prefixed with `/api/v1` unless noted.

## Authentication

All endpoints except `/auth/register`, `/auth/login`,
`/auth/forgot-password`, `/auth/reset-password` and `/auth/refresh`
require an `Authorization: Bearer <access_token>` header.

| Method | Path | Description | Rate limit |
|---|---|---|---|
| POST | `/auth/register` | Create an account, returns token pair | 5/min |
| POST | `/auth/login` | Email + password login, returns token pair | 5/min |
| POST | `/auth/refresh` | Exchange a refresh token for a new pair | — |
| POST | `/auth/forgot-password` | Request a password reset token | 5/min |
| POST | `/auth/reset-password` | Reset password using a reset token | — |
| GET | `/auth/me` | Get the current authenticated user | — |

**Login request body:**
```json
{ "email": "user@example.com", "password": "secret123" }
```
**Token pair response:**
```json
{
  "access_token": "eyJ...",
  "refresh_token": "eyJ...",
  "token_type": "bearer",
  "user": { "id": 1, "full_name": "Jane Doe", "email": "user@example.com", "role": "user", ... }
}
```

## Error format

All errors return:
```json
{ "detail": "Human-readable message." }
```
Standard HTTP status codes are used: `400` validation, `401` auth,
`403` forbidden, `404` not found, `413` file too large, `429` rate
limited, `500` unhandled server error.

## Security notes

- Passwords are hashed with bcrypt (`passlib`).
- JWTs are signed with `HS256` using `SECRET_KEY` — **rotate this in
  production** and never commit it.
- File uploads are validated by extension, size, and magic bytes, then
  stored under a UUID filename (never the user-supplied name) — see
  `backend/app/services/storage.py`.
- Sensitive routes are rate-limited via SlowAPI (see table above).
